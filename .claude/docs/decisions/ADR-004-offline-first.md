# ADR-004: Офлайн, без сети на старте

- **Статус:** Accepted
- **Дата:** 2026-10-29

## Решение

Приложение работает только с локальными данными: Room и DataStore. Сетевого слоя нет.

## Последствия

- Если появится бэкенд, сеть добавим отдельным ADR (планируется Ktor Client + kotlinx.serialization).
- Репозитории проектируются так, чтобы удалённый источник можно было добавить без изменения `core:domain`.
