# ADR-005: Многомодульность + convention plugins

- **Статус:** Accepted
- **Дата:** 2026-10-29

## Решение

Проект делится на модули `core:*` и `feature:*` (см. [architecture/modules.md](../architecture/modules.md)). Общая конфигурация сборки вынесена в convention plugins в included build `build-logic`.

## Альтернативы

- **Один shared-модуль** — быстрее старт, но границы держатся только на дисциплине.

## Последствия

- Явные границы между слоями и фичами, параллельная и инкрементальная сборка.
- Больше начальной настройки. Build-файлы модулей короткие: в них только плагины и зависимости.
