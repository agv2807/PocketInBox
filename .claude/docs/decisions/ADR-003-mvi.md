# ADR-003: MVI своей реализации

- **Статус:** Accepted
- **Дата:** 2026-10-29

## Решение

Слой представления — MVI поверх KMP `androidx.lifecycle.ViewModel`:
- **State** — неизменяемое состояние экрана, `StateFlow`;
- **Intent** — действия пользователя, единая точка входа в ViewModel;
- **Effect** — одноразовые события (навигация, тосты).

Базовые классы — в `core:common`. ViewModel внедряются через `koin-compose-viewmodel`.

## Альтернативы

- **MVVM** — проще, но слабее контролирует однонаправленный поток данных.
- **Orbit MVI** — готовая библиотека, но лишняя зависимость ради небольшого кода.

## Последствия

- Полный контроль над API, без внешней зависимости.
- Базовый контракт нужно спроектировать и поддерживать самим.
