# ADR-006: Use cases не обязательны

- **Статус:** Accepted
- **Дата:** 2026-10-29

## Решение

ViewModel обращается к интерфейсу репозитория из `core:domain` напрямую. Use case заводится только там, где есть логика, которую стоит переиспользовать или изолировать: комбинирование нескольких репозиториев, бизнес-правила.

## Альтернативы

- **Use case на каждую операцию** — единообразно, но порождает много классов, которые просто вызывают метод репозитория.

## Последствия

- Меньше бойлерплейта.
- Граница «когда нужен use case» держится на ревью, а не на правиле.
