# Обзор продукта

> Статус: окончательная идея продукта не описана. Стартуем с заметок.

- Пет-проект, платформы: Android и iOS.
- Работает офлайн, данные хранятся локально ([ADR-004](../decisions/ADR-004-offline-first.md)).

## Первая версия: заметки

Приложение запускается на обеих платформах и показывает один экран:
- список заметок из Room;
- пустое состояние, когда заметок нет;
- добавление заметки (FAB → ввод).

Цель версии — проверить весь стек: Room, Koin, MVI и навигацию на Android и iOS.

## Открытые вопросы

- Во что развивается PocketInBox после заметок.
- Поля заметки (минимум: id, текст, дата создания).
